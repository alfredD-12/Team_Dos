# Team Dos Image Upload

## Setup

Create a `.env.local` file in the project root:

```env
GYAZO_ACCESS_TOKEN=your_gyazo_access_token_here
```

Then run:

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.
